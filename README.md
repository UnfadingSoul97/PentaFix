# Features
 The main features are :
- 530x530x620 Print Area
- This thing is Crazy Cheap cuz 5 axis 3D printers seem to have special tax.
- It used Direct Drive and has Dual cooling whose design is similar to the Dragon V2
- it has a hybrid 4040 and 2040 frames.
- I also plan to make a heated Chamber but didnt have time to go into that so one i have built the 3d Printer i would make a case out of PETG then print it with ABS and vola I have a heated chambered 5 axis Printer costing around 680$ that would actually amounts to 4000$
- I can get stuff to be this cheap cuz I live in India ✌

I went with a simple CoreXY Design for the Motion and the Printhead is able to tilt more that 90 degrees to each side.
But i do need to buy a Digiial Caliper cuz need to take meassurements.
